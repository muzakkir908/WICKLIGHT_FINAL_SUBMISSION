# Note About AI Use

I used an AI assistant to help me make this project. This note shows what the AI did and what I did.

**AI tool:** Claude (made by Anthropic), used through Claude Code.

## Who did what

| Part of the project | Where it is | What the AI did | What I did |
|---|---|---|---|
| Game idea and rules | `01_Game_Concept/` | Wrote the game design document. | Chose the theme. Decided that the game must be simple: one level, 5 embers, moths, spikes, 3 lives, 60 seconds and one door. Checked the document. |
| Pixel art | `02_Pixel_Art_Assets/` | Made all the sprites, tiles, the background, the sprite sheets, the colours and the 6 Piskel files. The art was written as text maps in a computer program. It was not drawn by hand. | Asked for simple art that a beginner can open and change in Piskel. Checked the art. |
| Piskel check | `02_Pixel_Art_Assets/piskel/` | Opened all 6 Piskel files in the Piskel editor with an automatic test, and checked the frames, sizes, speed and colours. | – |
| Level design | `03_Level_Design/` | Designed the map, made the map pictures, wrote the notes and checked that every jump is possible. | Gave the rules for the level (one screen, one route, 5 embers, 2–3 spike groups, 1–2 moths, one exit). Checked the map. |
| Game screens | `04_UI_and_Prototype/screens/` | Made the 4 screens. | Checked the screens and asked for changes. |
| HTML prototype | `04_UI_and_Prototype/prototype/` | Made the HTML prototype and tested it. | – |
| Figma prototype | My Figma file | Made a small Figma plugin that puts the screens and the links into a Figma file. (The plugin is not part of this package.) | Made the Figma file, ran the plugin, tested every link in Present mode and set up sharing. |
| Documents | all `.md` files | Wrote the documents in simple English. | Asked for simple English, read the documents and filled in my details. |
| GitHub | the repository | Made the changes and the commits. The commits show my name because it is my repository. | Owns the repository and checked the files. |

## How I worked with the AI

I gave the AI instructions: what the game should be, what to make simpler and what to fix. I checked the results and asked for changes many times. For example, the first version was too difficult, so I asked for a much simpler game.
